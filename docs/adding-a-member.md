# Adding yourself to the Members page

The [Members page](https://www.wavlab.org/members/) is generated from a single
data file, so adding yourself means editing one YAML file and adding a photo.
You do not need to write any HTML.

Your publication list is fetched from Google Scholar automatically — you do not
create or edit it by hand.

---

## Before you start

You will need:

- **A photo.** Square works best; the card crops it to a 72px circle.
- **Your Google Scholar ID** (optional). Open your Scholar profile and copy the
  `user=` part of the URL:

  ```
  https://scholar.google.com/citations?user=U5xRA6QAAAAJ&hl=en
                                            ^^^^^^^^^^^^
                                            this is your scholar_id
  ```

  No Scholar profile? Leave it out. Your card still renders correctly, it just
  shows "No publications listed yet" and no Scholar link.

---

## Steps

### 1. Branch off `source`

The default branch is **`source`**, not `main`. Never edit `master` by hand —
it is generated by the deploy workflow.

```bash
git clone https://github.com/wavlab-speech/shinjiwlab.github.io.git
cd shinjiwlab.github.io
git checkout source
git pull
git checkout -b add-member-yourname
```

### 2. Add your photo

```bash
cp ~/Downloads/my-photo.jpg assets/img/yourname.jpg
```

### 3. Add yourself to `_data/members.yml`

Add an entry at the **end of your role's group**. Order within a group is the
order shown on the page.

```yaml
- id: your_name
  name: Your Name
  role: phd
  scholar_id: XXXXXXXXXXXX
  website: https://yourname.github.io/
  image: yourname.jpg
```

### 4. Preview locally

```bash
bundle install
bundle exec jekyll serve
```

Open <http://localhost:4000/members/> and check that your card appears in the
right section, your photo is not distorted, and your links work.

### 5. Open a pull request

```bash
git add _data/members.yml assets/img/yourname.jpg
git commit -m "Add Your Name to members"
git push origin add-member-yourname
gh pr create --base source --title "Add Your Name to members"
```

Add **only** those two files. Do not commit `_site/` — it is build output.

## Field reference

| Field | Required | Notes |
|---|---|---|
| `id` | yes | Unique, lowercase, `firstname_lastname`. Also the `_data/scholar_pubs/<id>.yml` filename. |
| `name` | yes | Shown on the card, exactly as written. |
| `role` | yes | Decides which section you appear in. See below. |
| `scholar_id` | no | The 12-character id from your Scholar profile URL. Without it, no publications are ever fetched. |
| `website` | no | **Must start with `http://` or `https://`**, otherwise it is silently dropped. |
| `image` | no | Filename inside `assets/img/`. |
| `note` | no | Shown in parentheses after your name, e.g. `co-supervising`. |

### Valid roles

```
faculty | postdoc | phd | master | visitor | industrial
```

> **Watch out:** a misspelled `role` makes you disappear from the page with no
> error message and no failed build — the section filter simply matches
> nothing. If your card does not show up, check this first.

## What happens to your publications

You do not need to do anything. The list fills itself in:

| When | What happens |
|---|---|
| Your PR is merged | Your card appears, showing "No publications listed yet". |
| The following Sunday | A scheduled workflow runs `bin/fetch_scholar.py`, creates `_data/scholar_pubs/<id>.yml`, fetches your papers, and opens a PR. |
| That PR is merged | Your publication list and count badge appear on your card. |

If you would rather not wait a week, run it yourself and include the result in
your own PR:

```bash
pip install scholarly pyyaml
python3 bin/fetch_scholar.py
```

Google Scholar rate-limits scrapers, so this sometimes fails. It is safe to
retry: the script refuses to overwrite good data with an empty or suspiciously
short result.

To only create the empty data files, without touching the network:

```bash
python3 bin/fetch_scholar.py --enrich-only
```

### Why your titles might look wrong

Google Scholar sentence-cases titles (`POWSM` becomes `Powsm`) and often
reports published papers as arXiv preprints. To compensate, every fetched
record is matched against the lab's curated `_bibliography/papers.bib`, and
where a paper is found there its title, venue, year and link are used instead.

**So the best way to fix your entry is to add the paper to
`_bibliography/papers.bib`.** That improves the Publications page and your
member card at the same time. After editing the bib file, re-apply it with:

```bash
python3 bin/fetch_scholar.py --enrich-only
```

Papers that are not in `papers.bib` keep whatever Scholar returned. The page
carries a note telling readers the lists are auto-fetched and may be wrong, and
points them at your own website.

## Changing or removing your entry

- **Change your photo, website or name:** edit your entry in
  `_data/members.yml` and open a PR. Nothing else references you.
- **Change your role** (e.g. Master to PhD): edit `role`. You move sections
  automatically; your publications follow you.
- **Leaving the lab:**
  1. Delete your entry from `_data/members.yml`.
  2. Delete `_data/scholar_pubs/<id>.yml`.
  3. Add yourself to the Alumni list at the bottom of `_pages/members.md`
     (that part is still hand-written HTML), with your dates and affiliation.

## Troubleshooting

**My card does not appear.**
Check `role` for typos — it must be exactly one of the six values above.

**My website link is missing.**
It must start with `http://` or `https://`. A bare `yourname.github.io` is
rejected on purpose, to stop broken and unsafe links reaching the page.

**My photo is squashed or off-centre.**
Cards crop to a circle using `object-fit: cover`. Crop your image square first.

**My publication count looks wrong.**
The badge is the number of distinct papers on your Scholar profile after
duplicates are merged, so it can differ from the number Scholar itself shows.
If it is badly wrong, your Scholar profile probably contains papers by somebody
else with your name — fix it there and it will correct itself on the next run.

**Only 20 papers are listed.**
That is deliberate. The card shows your 20 most recent and links to your full
Scholar profile.
