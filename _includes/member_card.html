{%- comment -%} Per-member card for the Members page. Expects: include.member — one entry from _data/members.yml (id, name, role, scholar_id, orcid, website, image, optional note). Publications are read from _data/member_pubs/.yml, which may legitimately be absent — a member added before the first refresh — so the lookup is guarded. Jekyll's `sort` filter raises "Cannot sort a null object" on nil input, which would abort the whole site build, not just this card. `concat` against an empty array is what makes that safe: it funnels the value through Liquid's InputIterator, so a missing file (nil) becomes [] rather than reaching a filter that rejects it. The stored order is authoritative and is NOT re-sorted here. bin/fetch_publications.py writes each file newest-first with a stable sort; Jekyll's `sort` uses Ruby's unstable `Array#sort!`, and the `| sort: "year" | reverse` idiom additionally reverses every same-year group, which scrambled which papers survived `limit:20`. Keep any reordering in the generator, not here. The publication data is auto-refreshed from papers.bib and from each member's public ORCID record, so every field is HTML-escaped and links are restricted to http(s) to avoid injection. Curated members.yml fields are escaped too for safety. `orcid` may be written as the bare iD or as an orcid.org URL; the URL prefix is removed so the link is not doubled. Every variable below is assigned on every branch: an include shares the page's variables, so a value left over from the previous card would otherwise leak into this one. {%- endcomment -%} {%- assign m = include.member -%} {%- assign data = site.data.member_pubs[m.id] -%} {%- assign empty_array = "" | split: "," -%} {%- assign pubs = data.pubs | concat: empty_array -%} {%- assign total = data.total | default: pubs.size | plus: 0 -%} {%- assign scholar = m.scholar_id | default: "" | strip -%} {%- assign scholar_url = "https://scholar.google.com/citations?user=" | append: scholar | escape -%} {%- assign orcid = m.orcid | default: "" | remove: "https://orcid.org/" | remove: "http://orcid.org/" | strip -%} {%- assign orcid_url = "https://orcid.org/" | append: orcid | escape -%} {%- if orcid != "" -%}{%- assign profile_url = orcid_url -%}{%- assign profile_name = "ORCID" -%} {%- elsif scholar != "" -%}{%- assign profile_url = scholar_url -%}{%- assign profile_name = "Google Scholar" -%} {%- else -%}{%- assign profile_url = "" -%}{%- assign profile_name = "" -%}{%- endif -%}
